# 2026-08-12

## 修复 MainScreen.kt 编译错误（Stats 未解析）
- 现象：`MainScreen.kt:43 / 223` 报 `Unresolved reference: Stats`，并连带 `Not enough information to infer type variable T` / `Property delegate must have getValue` 错误。
- 根因：`DouyinAccessibilityService.kt` 中 `Stats` 原本定义在 `companion object` 内；增量编译/IDE 缓存导致 `MainScreen.kt` 引用 `DouyinAccessibilityService.Stats` 时解析失败（旧构建残留）。
- 修复：将 `Stats` data class 从 `companion object` 内移到 `DouyinAccessibilityService` 直接嵌套类（更标准的写法），`DouyinAccessibilityService.Stats` 引用关系不变。需 clean rebuild 清除增量缓存。

## 修复 LogScreen.kt 实验性 API 报错（FilterChip）
- 现象：`LogScreen.kt:162/172/180/188` 报 `This material API is experimental...`（被 `-Werror`/allWarningsAsErrors 升级为错误）。
- 根因：`FilterChip` 为 `ExperimentalMaterial3Api`；文件仅在 `LogScreen` 上加了 `@OptIn(ExperimentalMaterial3Api::class)`，而 `FilterBar` 是独立函数、其函数体直接引用实验性 API，需自身注解。
- 修复：在 `FilterBar` 的 `@Composable` 前补 `@OptIn(ExperimentalMaterial3Api::class)`（该符号由 `import androidx.compose.material3.*` 覆盖）。
