# 2026-08-20 工作日志

- 抖音自动助手（douyin-auto-assistant）点赞方式改造：
  - 文件 `app/src/main/java/com/douyin/auto/DouyinAccessibilityService.kt` 的 `performLike()` 由「查找点赞按钮节点并点击」改为「在视频区域随机选点双击」。
  - 新增 `analyzeVideoForLike()`（单次遍历节点树：定位视频区域=优先视频渲染表面 TextureView/SurfaceView/VideoView，否则回退整屏去安全边距）、`pickSafeDoubleTapPoint()`（随机取点并避开所有可点击节点矩形禁区，外扩 SAFE_MARGIN_DP=10dp）、`dispatchDoubleTap()`（两次点按间隔 90ms 模拟双击）。
  - 先检测 LIKED_TEXTS（已赞/取消赞）命中则跳过，避免双击取消赞。
  - 目的：双击视频即点赞，且避开右侧点赞/评论/分享/头像等可点击位置，防止误触其它功能。
  - 注意：本沙箱无 Android SDK，未做 Gradle 编译验证；逻辑仅用标准 AccessibilityService/GestureDescription API。
