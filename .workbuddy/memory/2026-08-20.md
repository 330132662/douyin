# 2026-08-20 工作日志

- 抖音自动助手（douyin-auto-assistant）点赞方式改造：
  - 文件 `app/src/main/java/com/douyin/auto/DouyinAccessibilityService.kt` 的 `performLike()` 由「查找点赞按钮节点并点击」改为「在视频区域随机选点双击」。
  - 新增 `analyzeVideoForLike()`（单次遍历节点树：定位视频区域=优先视频渲染表面 TextureView/SurfaceView/VideoView，否则回退整屏去安全边距）、`pickSafeDoubleTapPoint()`（随机取点并避开所有可点击节点矩形禁区，外扩 SAFE_MARGIN_DP=10dp）、`dispatchDoubleTap()`（两次点按间隔 90ms 模拟双击）。
  - 先检测 LIKED_TEXTS（已赞/取消赞）命中则跳过，避免双击取消赞。
  - 目的：双击视频即点赞，且避开右侧点赞/评论/分享/头像等可点击位置，防止误触其它功能。
  - 注意：本沙箱无 Android SDK，未做 Gradle 编译验证；逻辑仅用标准 AccessibilityService/GestureDescription API。

- 修复「一直收藏失败」：
  - 根因：`findVideoActionNode()` 要求节点同时满足「文本含『收藏』」且「自身 isClickable」。抖音收藏按钮是「可点击容器 + 子 TextView 文字」结构，文字在非可点击子节点上 → 永远找不到 → 日志报「未找到收藏按钮」。
  - 改 `findVideoActionNode`：先按文本命中节点，再向上回溯最近的可点击祖先（含自身）来点击；遍历完一次性回收（root 与返回节点除外，避免重复回收/泄漏）。
  - `performCollect` 增加兜底：ACTION_CLICK 返回 false 时，改在按钮中心下发单击手势（dispatchTap），应对不响应无障碍点击的自定义 View。

- 直播跳过（不调用大模型）：
  - `IntentKeywords` 新增 `LIVE_TEXTS`（直播中/正在直播/进入直播间/离开直播间/退出直播间/直播间）。
  - `DouyinAccessibilityService` 新增 `detectLiveStream(root)`：遍历节点树命中任一 LIVE_TEXTS 即判定为直播。

  - `performCollect` 先 `findVideoActionNode`（文本）找不到时，重新取 `rootInActiveWindow` 快照调 `findCollectButtonByPosition` 兜底（因首次遍历已回收子树，必须换新快照）。命中后 ACTION_CLICK，失败再回退 dispatchTap 手势。

  - `LIVE_TEXTS` 改为：点击进入直播间 / 进入直播间 / 直播间 / 直播中 / 正在直播 / 直播 / live。
  - `detectLiveStream()` 改为返回 `LiveDetectResult(isLive, reason)`；扫描同时读 `hintText`（Build.VERSION.SDK_INT >= O），并记录弱信号便于校准。

  - `analyzeAndAct()` 内部检测同步改为读 LiveDetectResult.reason。
  - 验证建议：日志出现「检测到直播间（…），跳过」即生效；若仍漏判，把直播预览界面稳定出现的文字回传，加进 LIVE_TEXTS。

- 直播预览检测收敛（修复「直播广场」误命中）：
  - 现象：日志报「命中直播文本：直播广场」但屏幕无此字、代码也无此字。根因：旧 detectLiveStream 用 LIVE_TEXTS 全树 substring 扫描，裸「直播」二字命中了节点文本「直播广场」→ 误判为直播预览跳过。
  - 方案：强信号改用专用 `LIVE_CTA_TEXTS = ["点击进入直播间"]`，且要求节点 `isVisibleToUser` **并且** `isOnScreen(node)`（boundsInScreen 与屏幕矩形相交，过滤国产 ROM 下「逻辑可见但滑出屏幕」的残留节点）。
  - `IntentKeywords.kt` 新增 `LIVE_CTA_TEXTS`；`DouyinAccessibilityService.kt` 修 `isVisiable2User` 拼写错为 `visible` 并真正用上，新增 `isOnScreen()` 辅助函数，「点击进入直播间」只对用户可见且在屏内的节点才命中。
  - 效果：「直播广场」不再含「点击进入直播间」→ 不再误命中；只有真出现可见直播预览 CTA 才跳过。
  - 注意：`isOnScreen` 用 `resources.displayMetrics` 取屏幕矩形（服务即 Context）。未做 Gradle 编译（沙箱无 SDK）。
