# 2026-08-17 工作日志

## 新增：抖音视频内容分析功能（点赞/收藏自动判定）
在 DouyinAutoAssistant（Kotlin 无障碍服务 App）中新增「刷视频自动分析」能力：
- 流程：MediaProjection 实时截屏 → 视频前 N 秒随机截帧 → 提交用户配置的国产多模态大模型（OpenAI 兼容 /chat/completions）→ 模型返回 JSON{subject, tags, should_like, should_collect, reason} → 无障碍点击点赞/收藏。
- 关键新增文件：
  - `config/AppPreferences.kt`：api_base_url/api_key/model_name/analysis_enabled/auto_execute/like_criteria/collect_criteria/frame_count/capture_window_ms 配置（DataStore）。
  - `model/VideoAnalysis.kt`：VideoAnalysisResult。
  - `network/LlmClient.kt`：HttpURLConnection 多模态请求（无新依赖）。
  - `media/ScreenCaptureService.kt`：MediaProjection+ImageReader+VirtualDisplay 前台服务（mediaProjection 类型）。
  - `service/VideoContentAnalyzer.kt`：截帧+分析编排。
  - `DouyinAccessibilityService.kt`：performLike/performCollect、findVideoActionNode、detectVideoIdentity、startVideoWatch 等。
  - `ui/ModelSettingsScreen.kt`：模型配置+录屏授权+单帧测试。
  - Manifest 增加 INTERNET 与 foregroundServiceType=mediaProjection；MainActivity 新增 MODEL 页与 MediaProjection 授权 launcher；MainScreen 新增「模型」导航与统计；LogScreen 增加分析/点赞/收藏筛选。

## 注意事项（踩坑点）
- 抖音 resource-id 随版本变化，点赞/收藏/作者/文案的 id（IntentKeywords 中 LIKE_TEXTS/COLLECT_TEXTS/DOUYIN_VIDEO_AUTHOR_IDS/DOUYIN_VIDEO_CAPTION_IDS）若匹配不到需按真机布局微调。
- 无障碍服务 canPerformGestures=false，无法模拟上滑手势；翻到下一个视频用 ACTION_SCROLL_FORWARD 兜底，失败需手动上滑。
- 录屏授权必须在 Activity 中弹系统授权；ScreenCaptureService 用该 token 启动。
- API Key 明文存于 DataStore，个人工具可接受，生产需加密。
- 本沙箱无法编译 Android（无 SDK/网络），代码未经构建验证，需用户本地 gradle 编译。
