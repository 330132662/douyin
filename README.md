## 使用说明

1.  散步模式
   在抖音首页推荐页 ，播放视频，启动散步模式，本工具从前10秒会截屏几帧，通过配置好的大模型识别图片，通过本地存储的点赞收藏条件
 来决定是否做自动化的相关操作，每个视频决策完（自动点赞或收藏）之后 ，将是否点赞或收藏提示一下用户 ，自动切换到下一个视频  进行画面帧分析。
    散步模式 ，也就是为了能刷到系统算法匹配的视频，之前开发的属于养号模式，因为搜索结果 变动是很小的，这也是我跟几位经常使用抖音引流的朋友讨论后学习到的
  方案。

## 法律边界明确

法律风险这块我得跟你说清楚——这个工具踩的线比一般"自动点赞"脚本要敏感一些，因为它**同时用了无障碍模拟点击 + 系统录屏 + 把画面发给第三方大模型**三件事。我分层次说：

##### 一、你最可能遇到的（现实风险，概率最高）
- **账号封禁/限流**：抖音对自动化行为（高频点赞、收藏、关注、模拟手势上滑）有成熟的风控模型。轻则掉流量、弹验证码，重则直接封号。这是目前对你最确定的风险，没有法律层面问题，但设备/账号直接报废。
- 风控现在还会检测"帧分析 + 规律操作"这类非人行为模式，散步模式虽然是慢节奏，但动作太规律仍可能被识别。

##### 二、平台协议层面（违约，不是违法）
- 抖音《用户协议》《社区自律公约》明确禁止：使用脚本、机器人、模拟器、非官方客户端、自动化交互。**无障碍服务模拟点击 + 录屏绕过界面限制**，都属于协议禁止的"外挂/外挂类工具"行为。
- 后果：平台可依据协议封禁账号、拒绝服务，你难以主张权利（因为是你先违约）。

##### 三、法律层面（视用途而定）
1. **《反不正当竞争法》第12条**（互联网专条）：禁止用技术手段妨碍、破坏其他经营者（抖音）合法服务的正常运行。个人偶尔自用、非经营，一般不被认定为"经营者"；但**如果你拿它做商业获客、批量养号、刷量**，就可能被抖音或同行起诉不正当竞争。
2. **《个人信息保护法》**：这是本工具最容易被忽略的点——
    - 录屏截的是抖音界面，**会带上其他用户的头像、昵称、视频内容**；
    - 这些帧被发到你配置的**第三方国产大模型**做识别，等于把他人个人信息传输给了第三方处理；
    - 若涉及"公开场所个人信息"尚有争议，但把他人视频画面喂给外部 API，在 PIPL 下属于"向第三方提供个人信息"，原则上需告知同意——你显然做不到。
    - 建议：仅在自己刷到的视频上分析，不要截取/留存他人主页、评论区用户清单去做商业化利用。
3. **技术措施规避**：通过无障碍+录屏绕开抖音的正常交互限制，理论上接近"规避技术措施"，但通常不构成《著作权法》下的规避（抖音界面不是受保护作品），主要是协议违约问题。

##### 四、刑事边界（一般碰不到，但有个红线）
- 正常使用**不会**触刑。
- 红线是：**规模化刷量、虚假互动、流量造假、用于诈骗/引流黑产、破坏抖音服务器**。一旦涉及经营数额或造成平台损失，可能触及非法经营、破坏计算机信息系统罪等。个人自用、非盈利，离这条线很远。

##### 我的实操建议
1. **个人、小范围、非商业**地使用，风险可控（主要就是封号）；**不要**把它当"获客/养号"生产工具规模化跑。
2. **频率再保守一点**：即使散步模式，建议单账号每天点赞/收藏/关注总量设个硬上限（比如几十次），且动作间隔加随机抖动，降低风控命中。
3. **大模型那边**：尽量选你信任的、有数据安全承诺的国产厂商；不要用来截取含他人隐私的画面；API Key 不要外泄。
4. **用途自我约束**：只做"帮我筛选我想看的视频"，别做"批量关注潜在客户""自动评论引流"——后者才是法律风险的重灾区。

一句话总结：**个人自用、非盈利、低频，主要是账号封禁风险；一旦商业化/规模化/截留他人信息，就会从"违约"升级到"不正当竞争 + 个人信息违规"的法律风险区。**
